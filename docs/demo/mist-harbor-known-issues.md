# 已知边界

- 调查员职业固定为记者，八项属性、生命和理智固定；创建时只分配职业／兴趣技能点，不能自定义职业或属性。
- 当前只支持四项作者编写的人生经历：档案通信员、旧线事故记者、站务账簿抄写员、潮汐合影摄影师；不支持自由输入背景。
- 调查员确认即正式开局，档案在该战役中不可原地编辑；检查点副本继承同一档案。如需换卡，必须新建战役。
- 正式云模型只支持 DeepSeek；自由文本路由和 GM 叙述依赖可用的 DeepSeek 配置。Ollama 兼容代码保留但不是默认配置。
- 三小时按调查、对话和多路径探索估算，熟悉谜底的玩家会更快。
- 检查点复制恢复会自动进入新分支；来源分支保留不变。
- 当前不是完整 V1.0，没有通用作者工具、自动更新或多人模式。
- 任务所需的受限上下文会发送给 DeepSeek；API Key 由系统加密保存。
- 2026-08-24 的 Windows 打包已自然完成；应用仍使用 Electron 默认图标，`package.json` 未填写 description/author，main CJS 构建保留三条 `import.meta` 警告。这些不阻断运行，但属于发布前包装工作。
- 本轮只完成自动三图认证和打包 exe 启动烟测；由于执行环境没有 Windows 桌面交互／截图通道，真实 DeepSeek 下的三张截图人工回归仍待执行。
