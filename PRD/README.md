# AI TRPG Engine 需求文档

**AI TRPG Engine** 是本仓库的产品名，也是上游设计文档 [AI TRPG Engine](https://github.com/LinHouraisan/AI-TRPG-Enginee) 的名字。上游只有设计文档，没有可以运行的代码；本目录的任务，是把那份设计基线落成一套能照着做的需求，并且对齐仓库里已经存在的桌面程序。

文档里的跑团术语，一律以 [萌娘百科「桌上角色扮演游戏／术语」](https://zh.moegirl.org.cn/桌上角色扮演游戏/术语) 为准，并且与本地作者手册（`handbook/`）保持一致。代码中的标识符仍然使用英文。

## 一句话说明

玩家自始至终只跟一位主持人说话；掷骰、规则、房间、道具和剧情标记全部由程序掌管。聊天记录不是存档——一场团真正的权威，是「当前状态」加上「只能追加的事件记录」。建议行动只是替玩家降低门槛，用自然语言自由行动永远都是合法的。

## 现阶段不做的事

- 多人实时联机的团
- 给真人主持人用的工作台
- 大批自主 NPC 构成的社会模拟
- 宣称自己获得了《龙与地下城》或《克苏鲁的呼唤》的官方授权

## 术语表

面向玩家的文案一律使用左列的说法，括号里是圈内简称或英文原词。右列的技术名词不要写进给玩家看的句子里。

| 应用内用语 | 含义 | 不要混用 |
| --- | --- | --- |
| 桌上角色扮演游戏（TRPG） | 品类的全称，作动词时说**跑团** | 不要写成「聊天角色扮演」 |
| 主持人（GM） | 台前的唯一角色：主持、扮演、叙述，玩家只跟他一个人说话 | 后台的各个模块都不是主持人 |
| 守秘人（KP） | 《克苏鲁的呼唤》对主持人的称呼，本演示和手册里用这个 | 不要再给玩家挂一个「导演」对话框 |
| 玩家（PL） | 主持人以外的参与者 | 严格说主持人也是玩家，但文案里仍然只称呼前者为玩家 |
| 玩家角色（PC） | 玩家在团内扮演的那个人物，本演示中称**调查员** | 不要用「角色」一词同时指模型和人物 |
| 非玩家角色（NPC） | 由主持人扮演的人物 | 不要给每个 NPC 单独开一条聊天线程 |
| 团（游戏聚会） | 一次跑团聚会，前面可以带数词，例如「两团跑完」 | 不要把一晚上跑完的一次性模组叫成战役 |
| 战役（Campaign） | 一本漫长的模组，或者一串相关的模组，要跑很多次团才完得成 | 代码里的 `campaign` 对应「战役」或「可以续场的团」，不是一晚上的同义词 |
| 模组／冒险（Module） | 写给主持人用的情节、人物、地点的集合 | 不要拿「内容包」当面向玩家的说法 |
| 剧本（Scenario） | 篇幅比战役短，通常限定在一处地方，跑若干次团就能完成；几个剧本可以串成一场战役 | 与模组含义相近，本产品的短篇统一叫「剧本」 |
| 一次性模组（One-shot） | 专为一晚设计的模组，通常附带预先做好的人物卡 | 《寄宿公寓账本》就属于这一类 |
| 规则 | 大家共同认可、用来决定能做什么以及成功率多高的约定，也用来指代某一套具体的规则体系 | |
| 规则书 | 教人怎么玩的书，里面既有规则也有世设方面的支持 | **规则资料包**是规则书里可以运行的那部分摘录，不等于纸质书本身 |
| 核心规则／核心书 | 规则中最核心的部分，包含车卡所需要的全部基础内容 | |
| 扩展规则 | 核心之外的资源书 | |
| SRD | 以开放授权发布、可以自由引用的规则文档 | 本产品不附带官方 5e 或 CoC 的授权文本 |
| 房规 | 只在本团生效的例外规则，**不能**与规则书上的原则相提并论，也不能悄悄拿到别的团里去用 | 除非在某个地区被普遍采用，否则不要叫村规 |
| 人物卡 | 记录人物是谁、有什么本事的那张卡，网团里可以是一份文件；本演示中称**调查员卡** | AI 角色扮演里的「文字卡／人设卡」不是人物卡 |
| 车卡 | 填写人物卡的过程 | 第零聚会（车卡回）可以一起商量怎么车卡、怎么贴合世设 |
| 检定（判定） | 玩家角色做有风险、有意义的行动时，按属性或技能掷骰来决定成败 | 中文里不要写 check 或 DC，字段名可以保留 `dc` |
| 掷骰 | 记法是 **xDy**，例如 1d100、1d20；百分规则通常写作 1d100 | 主持人不得口头报一个点数来冒充掷骰 |
| 生命值 | 表示人物受伤的程度 | 代码里可以写 `hp` |
| 理智（SAN） | 克苏鲁向规则里的核心资源 | 给玩家看的文案写「理智」，不要只写 SAN |
| 世设 | 世界设定 | |
| 战报（REPLAY） | 把跑团的经过写成回顾性的文字 | 战报不是存档 |
| 灭团 | 所有玩家角色都死亡，团没法再继续 | |
| 撕卡 | 人物死亡或者无法复活时，把人物卡弃置掉 | |

导演、记忆、上下文调度这类幕后模块的名字，只出现在引擎文档和调试视图里，绝不出现在跑团桌上。
