# 技术选型

状态：仓库里已经落地的栈；V1.0 物理规格以 [`docs/05-implementation-design/`](../docs/05-implementation-design/README.md) 为准（Draft）  
原则：继续在本仓库上做，不另起一套程序。

`docs/00–04` 不锁供应商。本文件原先锁的是「把试玩和 V0.1 做出来」的栈。V1 Draft 另锁了一套物理绑定（Electron 主进程、`better-sqlite3`、类型化 `DesktopApi`、Windows x64）。**两套现在并存**：Demo 证明了事件内核；桌面程序还是 Tauri 聊天外壳。往 V1 走之前，先把外壳决策写成 Accepted，不要在代码里静默换栈。

## 1. 决定

现在的形态是对的：本地桌面程序、自带密钥或者本地模型、SQLite、带类型的工具调用、中文手册。引擎需求里说的那些「服务」都是逻辑职责，落地成同一个进程里的 TypeScript 模块，不是微服务。

| 需求 | 仓库里现在用的 | V1 Draft 锁的 | 现状 |
| --- | --- | --- | --- |
| 外壳 | Tauri 2 + Rust（`src-tauri/`） | Electron Main + Preload + Renderer | 未合流。Rust 只管窗口、钥匙串、插件 SQL／HTTP |
| 界面 | React 19 + Vite 7；桌面走 Tailwind／shadcn，V1 写 CSS Modules | React + Vite + Zustand + TanStack Query | Demo 桌已能玩；`src/` 仍是会话聊天页 |
| 权威库 | 桌面：`@tauri-apps/plugin-sql` 单文件；Demo：sqlite-wasm kvvfs | 主进程 `better-sqlite3`：`settings.sqlite` + 每场 `campaign.sqlite` | Demo 有事件／分支／检查点；桌面仍是 CRUD 会话表 |
| 跨进程 | 渲染进程直接 `invoke` + 插件 SQL | 类型化 `window.desktopApi`，渲染进程不许碰库 | 桌面违反 V1 安全边界 |
| 密钥 | `keyring` crate | Electron `safeStorage` / DPAPI | 都做到「密钥不进库」 |
| 模型调用 | 桌面：Vercel AI SDK 工具写库；Demo：Ollama + Zod 契约 | `AiOrchestrator` 任务登记（`gm.interpret_action`、`gm.narrate_result`…） | Demo 对齐「模型写不了事实」；桌面工具仍会写库 |
| 分发 | 开发机以 macOS + `tauri build` 为主 | V1.0 只正式支持 Windows x64 | 未合流 |

其余（Zod、Bun、手册用 Astro）两边都还能用。`src/lib/tools.ts` 里会写库的工具，对 V1 是非法的。

## 2. 现在不加的东西

- 把主持人、导演、记忆拆成多个进程
- Postgres、Redis、图数据库
- 向量库（先用 FTS5 加结构化过滤）
- Next.js 或者多租户的托管接口
- Python 系的多智能体框架
- 官方 5e 或者《克苏鲁的呼唤》的授权文本

如果到了 V0.x，长战役的检索确实被 FTS5 加事件扛不住了，再把嵌入向量当成**派生索引**引进来，但它永远不能当事实源。

## 3. 目标模块结构

```
src/
  engine/
    runtime/          协调器、回合路由、回合状态机
    rules/            加载规则资料包、检定、效果
    rng/              带种子的掷骰，与 turn_id 绑定
    scenario/         节点与剧情进度
    validate/         模式、不变量、版本
    visibility/       按听众切分的视图
    events/           只追加的事件记录与重放
    state/            当前实体、房间、道具、剧情标记
    save/             检查点、哈希、分支
    context/          上下文调度 + 临时上下文库（程序侧）
    ai/
      gateway.ts      模型进出、重试、用量
      gm.ts           主持人的提示词与输出联合类型
      director.ts     触发之后的导演提案
      memory.ts       批量生成的记忆候选
      contracts.ts    Zod 输出类型
  data/packs/         规则与模组的 JSON
  components/desk/    叙述、建议行动、检定明细、人物卡
handbook/             作者手册（保留）
```

内核的可运行参考在 **`demo/src/engine/`** 和 **`demo/src/store/`**，不是 `src/engine/`（那个目录还不存在）。现有的 `src/lib/tools.ts`、`check.ts`、`db.ts`、`prompt.ts` 不要再往聊天外壳上堆功能。下一步是按 V1 的 IPC／DDL 把 Demo 内核搬进主进程，而不是在 `src/` 里从零再写一遍。

## 4. SQLite 布局

权威表以 [V1 Persistence](../docs/05-implementation-design/03-persistence.md) 为准：`settings.sqlite` 里的 `campaign_catalog`、`app_settings`、`provider_instances`、`model_profiles`、`task_routes`、`installed_content`；每场 `campaign.sqlite` 里的 `branches`、`turns`、`operations`、`events`、`state_entities`、`rule_decisions`、`narrations`、`snapshots`、`checkpoints`、`content_bindings`、`background_jobs`。

Demo 现在实现的是子集：`campaign`、`branch`、`event`、`checkpoint`，外加非权威的 `message`。缺 `turns`、`operations`、`state_entities`、`rule_decisions`、`narrations`。桌面 `src-tauri/migrations/001_init.sql` 仍是战役／场次／消息／人物／遭遇的 CRUD 表，**不是** V1 权威模型。

永远不算权威的部分：对话记录。它只是为了让叙述读起来连贯，读档绝不能依赖它。

## 5. 模型的输入输出

- 主持人的结构化输出走 `generateObject` 或 `Output`，配合 Zod 联合类型。
- 工具要么只**读**（上下文调度），要么只**提议**（意图）。真正的写入统一走 `Runtime.commit`。
- 过了原型期，现有那些会写库的工具（`update_character`、战斗相关的变更）对主持人就是非法的，改由路由去调用领域函数。

本地默认用 Ollama 的 OpenAI 兼容接口，云端默认让用户自带密钥。能力登记先做一张静态表（上下文长度、是否支持工具、是否支持 JSON、本地还是云端）。

## 6. 测试

| 层 | 工具 |
| --- | --- |
| 规则、掷骰、提交、重放 | `bun test`（或 Vitest），纯 TypeScript |
| 资料包校验 | `bun run pack:lint` |
| 跑团桌 | 先靠手玩，日后再补组件测试 |
| 手册 | 在 CI 里跑一次 Astro 构建 |

金样测试：固定种子，配上脚本化的《寄宿公寓账本》输入，跑出来的事件记录和状态哈希必须完全一致。

## 7. 分发

- V1.0 正式目标：Windows x64（见 [18-release-compatibility](../docs/05-implementation-design/18-release-compatibility.md)）。macOS 上的 Tauri 开发流只服务当前试玩，不当作 V1 验收平台。
- 不做账号服务器。默认的遥测不保存密钥，也不保存完整提示词。

## 8. 明确不选的方案

| 方案 | 现在不选的原因 |
| --- | --- |
| 把引擎整段改写成 Rust | 等重放真的慢到不能忍再说。V1 的领域逻辑仍是 TypeScript，跑在主进程。 |
| 托管版主持人 | 破坏「本地优先」和「自带密钥」两条前提。 |
| LangGraph 这类多智能体操作系统 | 与「只有一位主持人在台前」「由程序提交」这两条原则冲突。 |
| 渲染进程直连 SQLite | 违反 V1 IPC／安全边界。桌面现状正是这样，必须改掉。 |

外壳从 Tauri 换成 Electron，是 V1 Draft 的决定，还不是 Accepted。没写成 Accepted 之前，不要把 `src-tauri/` 拆掉。
