# 从文档对齐到现在

日期：2026-08-19。  
起点：从 `main` 拉入 [`docs/05-implementation-design/`](../docs/05-implementation-design/README.md)，外壳锁定 Electron。  
终点：W0 可跑，金样对齐，酒馆卡自动车只是原型。

这不是 V1 Accepted，也不是 V0.1 发版说明。只记这一段仓库里实际做了什么。

## 1. 文档拉下来之后改了什么判断

`docs/05` 把 V1 钉死：Electron、主进程 `better-sqlite3`、类型化 `window.desktopApi`、正式分发 Windows x64。模块正文仍是 Draft。仓库里缺 `docs/superpowers/specs/2026-08-19-v1-technical-design.md`，在补上之前以 00–04 加 05 为准。

当时代码是两套：

| 套 | 是什么 | 后来怎么处置 |
| --- | --- | --- |
| `demo/` | W1–W4 已完成的事件内核 + 跑团桌，哈希 `b6506aeb` | 继续当游戏语义与 Renderer |
| `src/` + `src-tauri/` | Tauri 聊天壳，工具会写库 | 停用写库工具，不再跟 |
| `electron/` | 当时还没有 | 按 05 新建，承接权威提交 |

决定：不新建 `src/engine/`，不把外壳留在 Tauri。PRD 04／06 改成「先 W0，再 W5」。

## 2. W0 — 外壳与权威边界（已完成）

代码在 `electron/`。Renderer 是 `demo/` 那张桌，有 `desktopApi` 时不许直连 SQLite，也不许自己 `keeperNarrate`。

做成了：

1. Main／Preload／sandbox／contextIsolation／单实例。
2. `window.desktopApi`：`app`、`campaign`、`settings`（含密钥）、`turn`、`timeline`、`operation`。没有通用 `invoke`。
3. V1 DDL 在 `electron/sql/`。`settings.sqlite` + 每场 `campaign.sqlite`。事件改、删会被触发器挡住。
4. `turn:submitAction` 在主进程跑 `playTurn`（路由／裁定／提交），再 `keeperNarrate`（关掉模型用模板）。写入 `turns`／`events`／`rule_decisions`／`narrations`。同一 `commandId` 幂等。
5. `operation.subscribe` 只推 `operation.status`、`narration.delta`、`narration.completed`、`campaign.changed`。
6. `CredentialStore` + `safeStorage`。Renderer 没有 `getSecret`。落盘是 blob，不含明文。`safeStorage` 不可用时只允许进程内会话密钥。
7. `bun run content:pack`／`content:check`：八个 JSON → `.scenario-pack`（拒 zipslip／哈希不符／缺文件）。还不能在运行时从 ZIP 开团。
8. `src/lib/tools.ts` 写库工具已停。

验收：寄宿公寓金样哈希 **`b6506aeb`**。Electron 与 Demo 同一条路径。

```bash
cd electron && bun run persist:check && bun run gold && bun run content:check && bun run dev
cd demo && bun run smoke
```

## 3. 这一段修过的坑

- **查询抢回合号：** 背包询问等 query 曾占用下一个 `turn-${n}`，下一行动主键冲突。现用 `turn-ask-<operationId>`。
- **开发启动：** Vite 绑 `127.0.0.1:1421`。`dev.ts` 清掉 `ELECTRON_RUN_AS_NODE`（Cursor 壳会把它设成 1，Electron 退化成 Node，`app` 是 `undefined`）。
- **原生模块：** `bun install`／`postinstall` 按当前 Electron 版本拉 `better-sqlite3` 预编译（ABI 对不上会 `ERR_DLOPEN_FAILED`）。手动：`bun run rebuild:native`。
- 金样脚本：`electron/scripts/gold-path.ts`。

## 4. W5 开了一条窄缝：酒馆卡自动车（原型）

W5 正文是可分发表面。这一段只做了人设卡的窄切片，其余没动。

- `demo/src/cards/`：SillyTavern V1／V2／V3 JSON，PNG `chara`／`ccv3`。
- 按描述 + 场景 + 世界书做 CoC 7e **自动车**。种子来自卡面，同一张卡数值不变。
- 能力只标 **人设卡**（`character_card`）。数值全是 `generated`，`confirmed: false`。
- 卡里的 system／jailbreak 留在 `untrustedPrompts`，不升成系统指令。
- 顶栏「人设卡」可预览。`cd demo && bun run card:check`。
- **不进战役，不当模组，不覆盖林晚。**

说明书：[`demo/src/cards/README.md`](../demo/src/cards/README.md)。规格对照 [14-content-system](../docs/05-implementation-design/14-content-system.md)。

## 6. 2026-08-20 文档更新后的程序切片

`main` 上的五份文档改写：取消各领域 Analyzer，普通回合不同步 Information / Memory / Director。代码里先落地程序侧，再接可选 live：

- `demo/src/engine/routes.ts`：快路径 vs `free_action`（`gm.handle_free_turn` 同一 `modelTaskId`）
- `demo/src/engine/kernel.ts`：提交后校验引用和资源边界
- `demo/src/engine/story-monitor.ts`：节点变化、线索缺口、停滞；`directorDue` 只是旗标
- `demo/src/engine/recent.ts`：当回合玩家原文 + 叙述 + 已提交事件
- Information：`context_plan` + 事件事实 Proposal（候选、未确认）；live 失败退回程序
- Director Frontier：从 Monitor 重建；仅 `directorDue` 时调模型
- Memory：无损 fact delta → extract → 场景 consolidate；live 不写 `fact`
- 上下文双缓冲：preparing → 任务边界切到 current
- 调试：主持人勾「调试后台任务」后记录栏画冷路径（`ai/trace.ts` + `ui/JobTrace.tsx`），默认关，不写事实

`cd demo && bun run architecture:check`。

已接上：模型版 Information／Director／Memory（失败退回确定性，不挡回合）；SQLite 持久化 memory／frontier；设置页 `provider_instances`；人设卡确认写入；`electron` `package:win`；后台任务调试面板。
